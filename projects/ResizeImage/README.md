### アイコン用画像ファイルのサイズ変換
- Icon用ファイルとしてファイルのサイズ変換を行う。
- 変換後のサイズは、180x180、192x192、512x512の3種類に固定。defaultですべてにチェック。
- 入力用ファイルは、png, jpeg, heic のいずれか。
  - heic はブラウザが直接デコードできないため、heic-to (CDN) でPNGに変換してから処理する。
  - heic-to はheicを選択したときだけ読み込むため、png/jpegのみの利用ではCDNアクセスは発生しない。
  - heic かどうかは拡張子ではなく、ファイル先頭のftypボックス（mif1/msf1/heic/heix/hevc/hevx）で判定する。
  - 当初 heic2any を使ったが、同梱するlibheifが古く近年のiPhoneのheicが
    `ERR_LIBHEIF format not supported` で失敗するため、libheifへの追従が続いている heic-to に変更した。
    heic-to は wasm を別途取得しない単一ファイル構成のため、CDNのscriptタグ1本で動く。
- 「中央を正方形に切り抜く」をオンにすると、元画像の中央から最大の正方形を切り出してアイコンを生成する。
  - heicまたは非正方形の画像を読み込んだ時点で、自動的にオンになる（手動で変更可）。
  - 起動画像用モードでは縦横比を保持するため、この設定は無効。

### 起動画像用のサイズ変換
- 横幅(px)を指定して、縦横比を保持したままリサイズする。

### 出力形式
- PNG（デフォルト）または JPEG（品質0.9、背景は白で塗り潰し）を選択できる。
